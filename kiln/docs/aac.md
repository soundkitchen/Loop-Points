# aac(ADTS)

aac(ADTS のフレームを並べた AAC。拡張子 `.aac`)の読み込み(`src/aac.zig`)の設計と検証の記録。今は解析(`kiln.aac.probe`)だけで、切り出しは後の PR で足す。決定事項は [`draft.md`](draft.md) §2.8。

## 1. 扱う範囲と出所

- ADTS のヘッダは ISO/IEC 13818-7 / 14496-3 から書いた(外部のコードや表は取り込んでいない)
- フレームのヘッダだけを読み、音声データ(raw_data_block)は読まない(AAC のデコーダはない。特許の扱いはデコーダを作るときに決める。[`draft.md`](draft.md) §5)
- 先頭(ID3v2 タグがあればその後)に ADTS のフレームがあり、次のフレームも続く(か入力・タグが続く)ものだけを aac とみなす(`NotAac`)。チャンネル構成が 0(プログラム設定が音声データの中にある)のものは `UnsupportedFormat`

## 2. フレーム

- ヘッダは 7 バイト(CRC があれば 9 バイト)。同期ワード 0xFFF とレイヤー 00(MP3 はレイヤーが 00 でないので見分けられる)、MPEG の版、プロファイル(オブジェクトタイプ − 1。Main / LC / SSR / LTP)、サンプルレートの番号、チャンネル構成、ヘッダを含むフレームの長さ、フレームの中の raw_data_block の数(1〜4。それぞれ 1024 サンプル)
- 最初のフレームと版・プロファイル・サンプルレート・チャンネル構成が同じフレームだけを、同じストリームとして数える。続けて読んでいるフレームは、ヘッダが正しく入力に収まれば数える。途中のゴミの後は、次のフレームも続く位置を探して読み直す(偶然の同期ワードを避ける)
- 末尾のタグ(ID3v1 の `TAG`、APEv2、ID3v2)と、途切れた最後のフレームは数えない。入力の末尾から ID3v1・APEv2(フッタ)・フッタのある ID3v2 を取り除いてから読むので、途切れたフレームの長さの欄がタグの中で終わっていても数えない。フッタのない ID3v2 や APEv2 のヘッダは、次のフレームが続かないフレームの中にタグの始まりがあれば、そこで終わりとみなす
- 長さはフレームの数 × 1024(× raw_data_block の数)。ADTS には先頭の遅延と末尾の詰め物を書く場所がないので、それらも含む

## 3. HE-AAC(SBR / PS)

ADTS のヘッダのプロファイルには、中心の方式(AAC-LC など)しか書けない。HE-AAC でもヘッダは中心のレート(例: 22.05kHz)の AAC-LC に見え、HE-AAC v2 ではチャンネル数も 1 に見える。デコード結果はレートが 2 倍(44.1kHz)、v2 なら 2 チャンネルになる。

見分けるには、最初のフレームの音声データをスペクトルまで読み(AAC デコーダの前半)、その後ろの SBR / PS の印を探す必要がある。kiln はそれをしない(2026-11-10 の決定。[`draft.md`](draft.md) §2.8)。代わりに:

- `probe` はヘッダの値を返し、JS の `aac.probe` は `sbr: null`(分からない)を返す
- ブラウザでは、WebCodecs の `AudioDecoder` に最初の数フレームを渡すと、実際のレートとチャンネル数が分かる。Chrome 157 で、afconvert の HE-AAC / HE-AAC v2 の ADTS を `codec: 'mp4a.40.2'` とヘッダの値で設定してフレームをそのまま渡すと、最初の出力が 44.1kHz・2 チャンネル(フレームあたり 2048 サンプル)になった。`decodeAudioData` は AudioContext のレートに変換するので、元のレートは分からない

## 4. 検証

- テスト用のファイル(`testdata/` の ffmpeg と afconvert の AAC-LC、afconvert の HE-AAC。0.5 秒)で、フレーム数とレートが ffprobe と一致する。HE-AAC はヘッダでは 22.05kHz の AAC-LC に見える
- テストで、先頭の ID3v2、途中のゴミ、末尾の途切れたフレームと ID3v1 を足した入力のフレーム数が、元と同じになることを確かめる。MP3 を aac と見間違えないことも確かめる
- テスト用のファイルを壊したり途中で切ったりした入力で、Debug ビルドが止まらない
