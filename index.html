操作
  • 波形の 開始・終了 の線をドラッグして動かす。何もない所をドラッグするとスクロール、クリックするとカーソルを置く
  • 縦のホイール(トラックパッドのピンチ)で拡大縮小、横のスクロールで左右に移動。下の全体表示をクリック・ドラッグしてもその場所へ移動する
  • 数値の入力と微調整のボタンは、吸着せずにその位置へ置く。「◀ 0」「0 ▶」で前後のゼロクロスへ移る
  • Space でカーソルから再生 / 停止。再生中にループ区間を動かすと、止めずにそのまま反映される(再生位置が区間の外に出たら開始点から鳴らし直す)
  • 音源と JSON は、ボタンで選ぶか、ページのどこかにドロップして読み込む。複数の音源を読み込むと、上のセレクトで切り替えられる。音源はアップロードされない
  • 「JSON を書き出す」で保存先を選んで保存する。「JSON をコピー」でクリップボードに写す。どちらも、読み込んだ JSON にある音源の項目も含めて書き出す
  • 読み込んだ、または保存した JSON に「上書き保存」できる。読み込んだあとにファイルが変更されていたら確認を出す
  • JSON の duration と音源の長さが違うと警告を出す
  • 「クロップ」では、波形の 前端・後端 の線で残す範囲を決め、「切り出して保存」で書き出す。mp3 は再エンコードせずに mp3 で切り出すか、WAV にするかを選べる。WAV は WAV のまま切り出し、ほかの形式は WAV にする。書き出すと、その音源を開いてループのモードに戻り、ループの秒数も合わせる。JSON の保存は別に行う
  • クロップの範囲がループ区間にかかっている間は書き出せない。再生は前端から後端まで 1 回で止まり、線を動かすと止まる
